# Mini-Projeto-1---Varejo-Analise-de-dados-

Nesse projeto, foi feito um levantamento de dados a partir de um banco de dados de compras de um varejo do intervalo de 01/02/2022 até 19/08/2022. Foi verificado a quantidade de compras entre genêros, operações a partir das informações de quantidades de filhos dos clientes, formatação de valores nulos das colunas e insights comentados no final.
